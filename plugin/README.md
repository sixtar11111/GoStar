# GoStar plugin

Install **GoStar-0.6.1.nbm** with STAR Tools → Plugins → Downloaded, restart, and open Tools → GoStar.

- [Installation](../docs/INSTALL.md)
- [Aerodynamic reports](../docs/REPORTS.md)
- [Validation scope](../docs/VALIDATION_061.md)

Native simulation changes use the user-selected provider, current object catalog, preflight, recovery save and readback. Internal package and module IDs remain compatible with earlier releases. No Siemens libraries are bundled.
