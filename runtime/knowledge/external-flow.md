# GoStar guidance: external flow

These are engineering recommendations exposed to the selected model, not a second planner and not a universal recipe. Explicit user instructions and actual geometry take priority. Query current geometry bounds, body topology, symmetry and existing physics before edits. Build farfield extents from the full body size/span and relevant chord length; a span-based clearance must not be replaced by a small chord-only extent. Check root/symmetry intersection and closed-solid validity before meshing.

A distance of roughly 10–20 appropriate reference lengths is an initial external-domain estimate, not a validated domain-independence result. Choose boundary types for the actual compressibility and incidence: freestream is often useful in external compressible flow; velocity inlet/pressure outlet require a consistent inlet/outlet assignment. Resolve Mach and altitude to a consistent atmosphere and explicitly disclose assumptions. Surface target/minimum sizes, growth and prism layers must reflect curvature, leading/trailing edges, turbulence model, y-plus target and resources. Do not claim actual y-plus before a flow solution.

Use complete supported turbulence model chains, such as SA or SST with compatible wall treatment. If the user asks to follow a recommendation, apply the matching native action, read it back and report changes rather than merely repeating advice. Mesh generation, finite-step CFD and converged physical results are separate outcomes. Preserve original imported CAD; use explicit derived geometry repair and record changed topology.
